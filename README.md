## 🌍 Crypto Volatility Visualizer – Overview

The **Crypto Volatility Visualizer** is an interactive Streamlit-based dashboard designed to analyze and simulate cryptocurrency market volatility.  

This application helps users explore real-world crypto price trends while also experimenting with mathematical volatility patterns through simulations.

Live link:
https://cryptostimulation.streamlit.app/ 



## 🚀 Key Features

- 📈 **Market Trend Visualization**  
  Displays real crypto closing price movements over time.

- 📊 **Trading Volume Analysis**  
  Highlights market activity using dynamic volume bar charts.

- 📉 **Daily Volatility Range**  
  Compares high vs low price fluctuations to measure daily risk.

- ⚡ **Volatility Index Tracking**  
  Computes volatility using the difference between high and low prices.

- 🎛️ **Simulation Playground**  
  Users can generate custom market swing patterns using:
  - Sine Wave  
  - Cosine Wave  
  - Random Noise  
  - Combined Patterns  

- 💥 **Market Shock Mode**  
  Adds sudden disruptions to simulate unpredictable real-world crashes.

- 🔁 **Stable vs Volatile Comparison Mode**  
  Visual comparison between low-risk and high-risk market behavior.



## 🛠 Modules Used

- **Python**
- **Streamlit**
- **Pandas & NumPy**
- **Plotly (Interactive Graphs)**



##  Important Note (Recommended Setting)

For the best experience, please switch Streamlit to **Dark Theme**:

**Settings → Theme → Dark**

This ensures the dashboard visuals match the intended futuristic UI design.


## 🎯 Purpose

This project was created to enhance understanding of cryptocurrency volatility, risk analysis, and simulation-based learning through an interactive interface.
